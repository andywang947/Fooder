# Frontend

## Enviroment
node.js v23.10.0
npm 10.9.2

## Setup
set your app
```bash
npx create-expo-app@latest app_name
```
delete all the directory except node_modules
install packages
```bash
cd app_name
npx expo install expo-image
npx expo install expo-image-picker
```

## Start
run in your terminal
```bash
npx expo start
```
